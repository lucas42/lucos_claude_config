**`<host>-v4.s.l42.eu` is a deploy route, NOT a host alias. SSHing to one can land you on a different machine.**

Verified 2026-09-16 against both authoritative servers and by SSH.

## The zone

`s.l42.eu` is generated by lucos_dns from configy hosts. The template emits an `A` record **only** when a host has `ipv4`; a host with `ipv6` + `ipv4_nat` gets an `AAAA` plus a separate `<id>-v4` name. Current content:

- `avalon`  — A 178.32.218.44 + AAAA (has both)
- `xwing`   — A 152.37.104.10 + AAAA
- `salvare` — **AAAA only** (`2a01:4b00:8598:5a00:f669:f6da:e174:624b`), no A, by design
- `salvare-v4`, `xwing-v4`, `virgon-express-v4` — **all A 152.37.104.10**, the one shared NAT address

The template's own comment says why: CircleCI doesn't support IPv6, and the `-v4` names are kept separate "because the port config is very different for both".

## The trap

```
$ ssh lucos-agent@salvare-v4.s.l42.eu 'hostname'
xwing            # ← NOT salvare
```

Port 22 on 152.37.104.10 belongs to xwing. 2222 and 2022 are refused. So **an IPv4-only client cannot reach salvare by SSH by name at all.** Use the literal IPv6 address, which works:

```
ssh lucos-agent@2a01:4b00:8598:5a00:f669:f6da:e174:624b   # → salvare.s.l42.eu
```

## Don't mistake this for an outage

`salvare.s.l42.eu` "not resolving" is almost always the **client**, not the estate. The agent sandbox resolves via systemd-resolved → 192.168.5.2 (the Lima host DNS proxy), which returns NODATA for AAAA on many names — it gave nothing for salvare, xwing *and* google.com, while 1.1.1.1 / 8.8.8.8 / 9.9.9.9 all returned the records. avalon resolves salvare fine.

**Before calling it a DNS regression, check the zone serial.** It is an epoch timestamp: `date -u -d @<serial>`. On 2026-09-16 it read 1780876665 = **2026-06-07 23:57:45Z**, matching the generated file's mtime — i.e. untouched for three months, so nothing could have regressed. See [[feedback_check_reachability_first]] and [[pattern_l42_dns_apex_zone_outage]] (that one is the real-outage shape: *all* l42.eu SERVFAIL).
